# My-Main

Working repository. Skills for Claude Code live in
[`.claude/skills/`](.claude/skills/README.md) — fifteen of them: thirteen
design-taste skills vendored from
[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT), plus
`frontend-design` from [anthropics/skills](https://github.com/anthropics/skills)
(Apache 2.0) and `improve-codebase-architecture` from
[mattpocock/skills](https://github.com/mattpocock/skills), both installed with
`npx skills add`. They load automatically in any Claude Code session opened here,
except `improve-codebase-architecture`, which is invoked explicitly.
