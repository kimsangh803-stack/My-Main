# My-Main

Working repository. Skills for Claude Code live in
[`.claude/skills/`](.claude/skills/README.md) — sixteen of them: thirteen
design-taste skills vendored from
[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT), plus
`frontend-design`, `improve-codebase-architecture`, and `design-mobile-apps`
installed with `npx skills add` from
[anthropics/skills](https://github.com/anthropics/skills),
[mattpocock/skills](https://github.com/mattpocock/skills), and
[designed-by-ai/skills](https://github.com/designed-by-ai/skills) respectively.

Most load automatically in any Claude Code session opened here.
`improve-codebase-architecture` is invoked explicitly, and `design-mobile-apps`
needs a `SLEEK_API_KEY` and a paid sleek.design plan — see the
[skills README](.claude/skills/README.md) before using it.
